# DN EDITZ Portfolio

A responsive, single-page creative portfolio for Destiny Aigbefoh.

## Preview locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Sections
- Hero / introduction
- Creative services
- Selected projects and learning work
- About Destiny
- Creative process
- Contact via GitHub

## Customize before sharing widely
- Replace the stylized project artwork with screenshots, thumbnails or links to the actual finished work.
- Add a professional email address and preferred social links when ready.
- Add real client testimonials only with permission.
- Update project statuses and descriptions as work is completed.

Built with HTML, CSS and vanilla JavaScript.
